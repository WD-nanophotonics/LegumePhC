# LegumePhC scientific work

This is a small scientific cross-validation project. Work directly in the
Windows `.venv`; never invoke WSL, Meep, MPB, Thin Flow, Courier, a service, or
a second worker.

The active route is: homogeneous calibration -> G15/Circle/G16 three-point C3
pilot over `gmax=2,3,4,5` and declared Berry steps -> evidence report. Do not
start GME, a full Berry map, UI work, or migration until the 2-D PWE pilot is
qualified. GME is a later, explicitly different slab model.

Preserve every result directory. Never overwrite or delete scientific output.
Large `fields.npz` files stay out of Git; commit frozen configs, tests, compact
summaries, plots, and reproduction commands to `sandbox`. Do not move `main`.

Prefer scientific work over framework work. Do not add orchestration, ledgers,
approval gates, state machines, or compatibility layers. A local implementation
or test failure is ordinary work: diagnose it once, repair it, and continue.

Do not compare raw complex eigenvectors. C3 conclusions use frequencies,
spatially rotated scalar field densities, subspace projectors, and gauge-
invariant Wilson loops. Never average C3 sectors, smooth data, copy sectors, or
delete spikes to manufacture agreement. Withhold rank-1 Berry whenever gap,
association, link magnitude, or branch margin is not qualified.

Before becoming idle, send the fixed supervisor task
`01a04136-7e60-75c3-88cf-156581a3733e` a compact report containing the latest
scientific result, failed/passed criterion, exact next scientific test, and
whether any solver run is uncertain. A negative result closes only that branch;
it does not terminate the project. Never create or fork another worker.
